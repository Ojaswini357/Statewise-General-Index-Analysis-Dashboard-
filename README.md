# Statewise General Index Analysis Dashboard (2011–2023)

## Project Overview
This project uses Microsoft Excel to analyze state-wise General Index data from 2011 to 2023. The interactive dashboard helps users explore index trends across Rural, Urban, and Rural+Urban sectors.

## Tools Used
- Microsoft Excel
- Power Query for data cleaning and transformation
- PivotTables and PivotCharts
- Slicers for interactive filtering
- KPI cards for summary metrics

## Key Features
- Cleaned and transformed the dataset for analysis.
- Created an interactive monthly trend line chart.
- Compared General Index values across different sectors and states.
- Added KPI cards to display average, minimum, and maximum index values.
- Used slicers to filter data by state, year, and sector.

## Objective
The objective of this project is to make state-wise and sector-wise index trends easier to explore and compare through an interactive Excel dashboard.

## Project Files
- `Project Excel.xlsx` — Excel workbook containing the dashboard and analysis.

## How to Use
1. Download the Excel workbook.
2. Open it in Microsoft Excel.
3. Use the slicers to filter the dashboard by state, year, or sector.
4. Explore the charts and KPI cards to understand the data.
